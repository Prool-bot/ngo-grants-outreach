# NGO Grants — каталог і моніторинг закупівель

Поштовий модуль вилучено з активної гілки. Немає SMTP, IMAP, автоматичних розсилок і поштових звітів. Окремий модуль збирає тільки оприлюднені загальні контакти організацій для ручного використання. Історичні дані CRM не видаляються.

## Незалежний каталог

Workflow `catalog-research.yml` працює щодня о 06:00 UTC (09:00 Europe/Istanbul), вручну або після зміни коду. Публічні довідкові джерела Wikimedia/Wikidata, ROR, Crossref; галузеві ресурси TED, HDX, MusicBrainz, Art Institute of Chicago та Crossref Works. Накопичення за ідентифікаторами, звіт про наповнення категорій, окремий звіт про помилки джерел. Артефакти зберігаються 90 днів. Записи потребують перевірки; каталог не є повним реєстром організацій.

## Робочий каталог контактів
Workflow `contact-catalog.yml` запускається за змінами коду, вручну та щодня о 06:30 UTC (09:30 Europe/Istanbul). Модуль `catalog_research.contact_sync` доповнює вкладку «Індивідуальні контакти» у CRM: назва, профіль, Email, телефон, місто, код категорії, категорія, короткий опис діяльності, ручний статус контакту та сайт/офіційна сторінка. Використовує раніше відомі офіційні сторінки, сайти організацій із вкладки «Кандидати» й офіційні сайти Wikidata з вкладки «Каталог організацій». Нові записи додаються за наявності п'яти основних полів і однозначної відповідності категорії з класифікатора. Опис береться з метаданих офіційного сайту або позначається як попередній. Існуючі значення й ручні статуси не перезаписуються; після циклу всі десять колонок сортуються разом за кодом категорії та назвою організації. ZZ-00 — тимчасова група для записів, що потребують уточнення. Джерело та дата перевірки — у примітці клітинки. Публічні загальні канали, без іменних контактів, без автоматичної розсилки, без публікації контактних даних в артефактах. Ліміт 20 перевірок за цикл, з ротацією. Знайдена адреса не підтверджує згоди на отримання пропозиції.

## Моніторинг закупівель

Workflow `outreach.yml` залишено для сумісності з наявним cron-job.org. Режим monitor — Пн–Пт 09:00–17:59 Europe/Istanbul. Режими check, preview, pilot, sources-check, registry-audit — дослідження та контроль реєстру. Режим report залишено лише як порожню сумісну відповідь; пошта не використовується. Старе завдання cron-job.org з mode=report можна вимкнути.

Потрібні лише GOOGLE_SERVICE_ACCOUNT_JSON, CRM_ID та EXPECTED_GMAIL (ідентифікатор наявного реєстру, не пароль). EMAIL_APP_PASSWORD та EMAIL_ADDRESS більше не використовуються; їх можна видалити з GitHub Secrets та відкликати відповідний пароль застосунку, якщо він не використовується іншими сервісами.
